# Sonidos distractores CPT

Puedes agregar estos archivos cuando quieras usar sonidos reales:

```text
beep.mp3
door.mp3
footsteps.mp3
radio.mp3
mechanical.mp3
alarm.mp3
robot-motor.mp3
```

Ruta base:

```text
public/assets/audio/space/distractors/
```

Si falta un archivo, el sistema usa un sonido procedural equivalente y continua funcionando.
